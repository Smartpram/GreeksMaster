## 💡 CONFIGURATION OPTIONS

### Sentiment Weight
- **0.20** = Conservative (20% sentiment, 80% price)
- **0.30** = Balanced (30% sentiment, 70% price) ← RECOMMENDED
- **0.40** = Aggressive (40% sentiment, 60% price)
- **0.50** = Extreme (50% sentiment, 50% price)

### Lookback Period
- **6 hours** = Intraday trading
- **24 hours** = Day trading ← RECOMMENDED
- **48 hours** = Swing trading
- **168 hours** = Weekly trading

### Sentiment Threshold
- **0.2** = Very sensitive (more signals, more noise)
- **0.3** = Standard ← RECOMMENDED
- **0.5** = Conservative (fewer, higher quality signals)
- **0.7** = Very conservative (only very strong signals)
