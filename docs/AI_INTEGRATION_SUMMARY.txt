## 🔌 Integration Points

### API Endpoints (Add to Your Flask App)

```python
@app.route('/api/ai/signals')
def get_ai_signals():
    """Get current AI trading signals"""
    signals = ai_bridge.generate_signals_for_watchlist(['SBIN', 'INFY', 'TCS'])
    return jsonify(signals)

@app.route('/api/ai/performance')
def get_ai_performance():
    """Get AI performance metrics"""
    report = ai_bridge.get_performance_report()
    return jsonify(report)
```

### Order Execution

```python
# When executing AI signals
for stock, signal in signals.items():
    if signal['confidence'] > 0.65:
        # Execute trade
        order = order_manager.place_order(
            stock=stock,
            side=signal['action'],  # BUY or SELL
            price=signal['entry_price'],
            stop_loss=signal['entry_price'] * (1 - 0.01)
        )
```

## 📈 Signal Format

All signals follow this structure:

```python
{
    'action': 'BUY' or 'SELL',           # Trading action
    'confidence': 0.85,                  # 0-1 confidence score
    'entry_price': 450.50,               # Suggested entry price
    'stop_loss': 445.99,                 # Stop loss level
    'target': 459.51,                    # Profit target
    'signal_source': 'combined_technical_ai',  # Where signal came from
    'technical_confidence': 0.80,        # Traditional TA confidence
    'ai_confidence': 0.90,               # AI model confidence
    'indicators': {...},                 # Technical indicators
    'ai_details': {...}                  # AI model details
}
```

## 🐛 Troubleshooting

### Issue: "ModuleNotFoundError: No module named 'ai_trading_engine'"
**Solution**: Check files are in c:\Data\MyBreezeApp\ root directory

### Issue: "AI not initialized"
**Solution**: Call `bridge.initialize_ai()` before generating signals

### Issue: "No signals generated"
**Cause**: Not enough data or confidence too high  
**Solution**: 
- Use 100+ data points
- Lower confidence threshold
- Check for data quality issues

### Issue: "Signal format different"
**Solution**: Use signals as-is, they follow defined structure above
