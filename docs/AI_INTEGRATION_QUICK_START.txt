## Step 3: Add to Your App (10 minutes)

```python
# In app/main.py - Add these imports:
from app.services.ai_signal_bridge import AISignalBridge
from app.strategies.ai_enhanced_strategy import AIEnhancedStrategy

# In create_app() - Add after other services:
ai_bridge = AISignalBridge(breeze_service, data_stream_service)
ai_bridge.initialize_ai()

ai_strategy = AIEnhancedStrategy(
    order_manager, risk_manager, notification_service,
    enable_ai=True, ai_confidence_threshold=0.55
)
ai_strategy.set_watchlist(['SBIN', 'INFY', 'TCS', 'HDFC'])
```

## Step 4: Generate Signals

```python
# Get market data
market_data = {
    'SBIN': get_ohlcv_data('SBIN'),  # List of dicts
    'INFY': get_ohlcv_data('INFY'),
    'TCS': get_ohlcv_data('TCS')
}

# Generate AI signals
signals = ai_strategy.generate_signals(market_data)

# Execute if confident
for stock, signal in signals.items():
    if signal['confidence'] > 0.65:
        print(f"BUY {stock} at {signal['entry_price']}")
        order_manager.place_order(stock, signal['action'])
```

## Configuration

```python
# Adjust these for your needs:

AI_CONFIG = {
    'enable_ai': True,              # Use AI (True/False)
    'confidence_threshold': 0.55,   # Min 55% confidence
    'position_size_pct': 2.0,       # Risk 2% per trade
    'stop_loss_pct': 1.0,           # 1% stop loss
    'take_profit_pct': 2.0,         # 2% target
}

strategy = AIEnhancedStrategy(
    ...,
    enable_ai=AI_CONFIG['enable_ai'],
    ai_confidence_threshold=AI_CONFIG['confidence_threshold']
)
```

## Common Issues & Fixes

### "No signals generated"
→ Need 100+ data points, check data quality

### "Confidence too low"
→ Lower threshold from 0.55 to 0.50

### "Import error"
→ Verify files in c:\Data\MyBreezeApp\ root

### "AI not initialized"
→ Call `bridge.initialize_ai()` or `strategy.setup()`
