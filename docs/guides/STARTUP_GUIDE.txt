📞 TROUBLESHOOTING QUICK REFERENCE

Problem: "Authentication Failed"
Solution: Get fresh session token from:
         https://api.icicidirect.com/apiuser/login?api_key=YOUR_KEY
         Update BREEZE_SESSION_TOKEN in .env file

Problem: "No Trades Generated"
Solution: Check if RSI thresholds are reasonable for current data
         Run optimization to find better parameters
         Try different strategy (SMA crossover)

Problem: "Poor Performance"
Solution: Verify on different stocks
         Check market conditions (trend vs range-bound)
         Review optimization results
         Try alternative parameters

Problem: "Breeze API Error"
Solution: Verify internet connection
         Check session token validity
         Restart authentication
         Check breeze_api.log for details
